# 캐릭터 이미지

`js/app.js` 의 `CONFIG.useImages` 가 `true` 이면 이 폴더의 이미지를, `false` 이면 `index.html` 안의 직접 그린 SVG를 씁니다.

| 파일 | 쓰이는 상태 |
|---|---|
| `idle.png`  | 대기 · 고민(갸웃) · 떨림 (기울기 · 식은땀 · 효과선은 CSS) |
| `happy.png` | 펑! 점프 |
| `eat.png`   | 결과 (맛있게 먹기) |

- 투명 배경 PNG, 640×680 캔버스에 캐릭터를 아래 정렬로 맞춰 두면 포즈가 바뀌어도 위치가 튀지 않습니다.
- 원본 이미지는 `_source/` 에 두고 git 에서 제외합니다.
- 다른 포즈를 추가하려면 파일을 넣고 `CONFIG.images` 의 상태 → 파일 매핑만 바꾸면 됩니다.
